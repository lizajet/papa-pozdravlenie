# Papa Pozdravlenie

Рабочий проект интерактивной поздравительной истории.

Формат вдохновлён механикой персонального веб-путешествия: герой перемещается между сценами, встречает близких людей, открывает воспоминания и собирает символические достижения. Код, визуальные материалы и сценарий создаются заново.

## Статус

Сейчас проект находится на стадии проектирования. Зафиксированы техническая архитектура, модель контента и порядок производства.

## Принятые исходные решения

- веб-приложение без серверной части;
- статическая публикация на GitHub Pages;
- React, TypeScript и Next.js со статическим экспортом;
- сцены описываются данными, а движок отвечает за переходы и отображение;
- фоновые иллюстрации, персонажи и декоративные эффекты собираются слоями;
- звук запускается только после явного действия пользователя;
- проект должен работать без регистрации, аналитики и передачи личных данных.
