# Сценарно-нейтральная модель контента

## Статус

Сценарий не зафиксирован. Не определены количество сцен, маршрут, число участников, способ появления поздравлений, система наград и финальная форма.

Этот документ описывает только технические сущности, из которых позднее можно собрать выбранный опыт. Ни одна сущность не является обязательной.

## Термины

- **Опыт** — весь пользовательский сеанс от запуска до завершения.
- **Блок** — необязательная группа сцен, объединённых общей темой.
- **Сцена** — одно визуальное состояние экрана.
- **Переходная сцена** — автоматическое движение между смысловыми сценами.
- **Памятный момент** — возможный визуальный эпизод, основанный на событии или образе.
- **Послание** — текст от близкого человека.
- **Коллекционный элемент** — необязательная награда, символ, качество или памятный объект.

## Открытые сценарные параметры

- линейный, ветвящийся или исследовательский маршрут;
- наличие одного героя или нескольких точек зрения;
- использование реального пространства, метафорического мира или временной линии;
- наличие встреч, посланий, воспоминаний и коллекционных элементов;
- способ завершения опыта;
- желаемая продолжительность;
- соотношение юмора, теплоты и торжественности.

Эти параметры заполняются только после сбора материалов и обсуждения концепций.

## Возможные шаблоны сцен

Названия ниже обозначают технические шаблоны интерфейса, а не порядок будущего сценария.

### `opening`

Титул, место действия и первая кнопка. Допускается медленное движение камеры.

### `travel`

Герой автоматически проходит по заранее определённой траектории. Завершение — событие анимации с резервным таймером.

### `encounter`

Герой встречает человека или значимый объект. Может быть самостоятельной сценой или началом памятного момента.

### `memory`

Иллюстрация или медиакомпозиция с короткой фразой и одним действием.

### `message`

Портрет, личный текст, подпись и необязательная информация об открытом коллекционном элементе.

### `transformation`

Переход в условный или фантастический мир: сон, VR, воспоминание, воображение. Используется редко как визуальная кульминация.

### `finale`

Технический шаблон завершения. Его содержание определяется только после выбора сценарной концепции.

## Черновая схема данных

```ts
type SceneType =
  | "opening"
  | "travel"
  | "encounter"
  | "memory"
  | "message"
  | "transformation"
  | "finale";

type StoryScene = {
  id: string;
  number: number;
  type: SceneType;
  ariaLabel: string;
  next?: string;
  background?: ImageAsset;
  layers?: SceneLayer[];
  copy?: {
    eyebrow?: string;
    title?: string;
    body?: string;
    action?: string;
  };
  messageId?: string;
  collectibleIds?: string[];
  completion: CompletionRule;
};
```

## Модель участника

```ts
type Person = {
  id: string;
  name: string;
  relationship: string;
  portrait: ImageAsset;
  message: string[];
  memories: MemoryReference[];
};
```

Текст хранится абзацами, а не одной строкой. Это позволяет управлять ритмом карточки и проверять допустимую длину.

## Модель коллекционного элемента

```ts
type Collectible = {
  id: string;
  title: string;
  description: string;
  authorId: string;
  badge: ImageAsset;
  detailArt: ImageAsset;
};
```

Если сценарий использует достижения, хороший элемент:

- состоит из 2–5 слов;
- узнаваемо для героя и его окружения;
- связано с конкретной историей;
- звучит тепло, даже если основано на подколе;
- имеет понятный визуальный символ.

## Ограничения контента

- памятная фраза: до 100 знаков;
- подпись кнопки: желательно до 28 знаков;
- заголовок достижения: до 42 знаков;
- описание достижения: 1–2 предложения;
- основное послание: ориентир 500–1200 знаков;
- длинные послания разбиваются на абзацы;
- на одной сцене не должно быть двух конкурирующих действий.

## Материалы для будущего сценарного обсуждения

До написания сценария нужно собрать:

1. Краткий портрет главного героя.
2. Повод и дату поздравления.
3. Список участников и их отношения с героем.
4. По 1–3 характерных истории от каждого участника.
5. Локальные мемы, цитаты и речевые особенности.
6. Значимые места, предметы, занятия и мечты.
7. Фотографии для сходства персонажей.
8. Желаемый эмоциональный диапазон и границы допустимого юмора.
9. Возможные ощущения после завершения — без выбора конкретного финала.

## Процесс до фиксации сценария

1. Собрать сырой материал без сокращений.
2. Выделить повторяющиеся темы, качества и образы без группировки в главы.
3. Составить несколько принципиально разных концепций опыта.
4. Оценить каждую концепцию по эмоциональности, срокам и стоимости ассетов.
5. Выбрать направление отдельным решением.

Редактура, структура эпизодов и производство финальных иллюстраций начинаются после этого решения.
